# GetSpot Marketing Site

The public marketing/landing page for GetSpot, served at `www.getspot.org` / `getspot.org`. Built with Next.js (App Router) — see `src/app/page.tsx` for the page content and `src/app/layout.tsx` for the shared layout.

This is a separate app from the Flutter product (`app.getspot.org`, deployed from the repo root). Old `/join/{code}` links on this domain 302-redirect to `app.getspot.org/join/{code}` (see `docs/hosting/README.md` and `docs/DEEP_LINKS.md` for the redirect setup).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build & Deploy

```bash
npm run build   # static export to main/out
```

Deployment is automated via `.github/workflows/firebase-hosting-merge.yml` on push to `main` — it builds this app and deploys `main/out` to the `main` Firebase Hosting target (see `firebase.json`). No manual deploy steps are needed.
